# メルカリ一括値下げ（Tampermonkey）

メルカリの「出品した商品」画面にパネルを出し、出品中の商品を決めた率（3/5/7/10%）や金額で、1品ずつ順番に値下げするユーザースクリプトです。

## 入れ方
1. Chrome に [Tampermonkey](https://www.tampermonkey.net/) を入れる
2. Chrome の拡張機能の画面で Tampermonkey の「詳細」→「ユーザースクリプトを許可」をオンにする
3. 次のURLを開き、「インストール」を押す
   https://raw.githubusercontent.com/TAKUTO2W/mercari-nesage/main/mercari-nesage.user.js

新しい版は Tampermonkey が自動で取り込みます。

## 使い方
1. メルカリの「出品した商品」画面を開く（右下にパネルが出る）
2. 率か金額、下限、1日の上限、間隔（秒）を決める
3. 「① 出品中の商品を読み込む」→ 下げる商品を選ぶ
4. 「試し（保存しない）」で確かめてから、「値下げ開始」を2回押す

## 注意
- 自動での操作は、メルカリの規約上グレーです。アカウント停止のおそれがあるため、1日の件数と間隔は控えめにしてください
- 同じアカウントで、2台以上同時に動かさないでください（二重に値下げされます）
